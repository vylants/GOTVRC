Moderator sign-in

Sign in with a GitHub token that has write access to this site’s repository. Approved houses are saved to houses.json and appear for every visitor.

One-time setup: create the repo (e.g. on GitHub Pages), then make a token at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Give it access to this repo with Contents: Read and write. You can pre-fill owner/repo/branch in js/admin-config.js.
